# Code of Conduct

## Our pledge

We want this repository to stay a place where people can improve a public,
recomputable AI-activity index without harassment or bad-faith disruption.

## Standards

**Do**

- Focus critique on the method, the code, and the data — not on people.
- Assume good intent when someone reports a score mismatch or a dark source.
- Keep security reports private until they can be fixed or rotated.

**Do not**

- Harass, dox, or threaten anyone involved with the project.
- Spam issues, PRs, or social channels linked from this repo.
- Post secrets, personal data, or exploit details in public issues.
- Use the project to push scams, malware, or undisclosed affiliate schemes.

## Scope

This applies in GitHub issues, pull requests, discussions, and any official
project channels tied to this repository.

## Enforcement

Report concerns to the repository maintainers via a private security advisory
or by contacting the account that owns
[messagegabrielhere-lgtm/doomcon](https://github.com/messagegabrielhere-lgtm/doomcon).

Maintainers may warn, edit, or remove content, and may block accounts that
repeatedly violate these standards.
