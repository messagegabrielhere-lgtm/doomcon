BLISS

The upside index

The other ending.

Every AI index measures how bad. This one measures the other direction, with the same machinery: five pillars, the same percentile normalisation against a frozen reference, the same smoothing, the same anti-flap rules. DOOMCON counts takeover-adjacent tempo. BLISS counts science, medicine, access, adoption and openness. Neither is a prediction.

The pairing is the instrument. Two numbers computed by identical code over different inputs can be subtracted. Two numbers produced by human or model judgement cannot. That is the whole argument for publishing both.

The two indices cannot be compared in this build.

BLISS has no frozen reference distribution yet, so its sources are collected and published but not scored. Both scores are percentile positions against each index's own frozen reference, so the subtraction is only meaningful when both exist. There is no number here rather than a zero, because a zero is a reading somebody could have earned and this is the absence of one.

Both axes are the same 0–100 scale with the same band floors at 35, 55, 70 and 85. A score is a percentile position against that index's own frozen reference distribution — never a probability, and never a comparison between the two fields.

BLISS is awaiting its baseline

10 of 10 sources are reporting and 10 of them have no frozen reference distribution to be scored against yet. A score is a percentile against a frozen record of how this source normally behaves; until that record exists there is no percentile to compute, so there is no number here.

This is the same state DOOMCON's markets pillar sits in, and it is deliberately not the same thing as dark. Dark means a pipe is dead. Awaiting baseline means the measurement is arriving and the ruler has not been built yet. Every value the sources returned is published below, unrounded and with its unit, so the record being accumulated is visible while it accumulates.

Nothing on this page is imputed, back-filled or estimated in the meantime. The alternative — printing a plausible number over an empty reference — is the failure this project was built in reaction to.

How this is computed

  1. Normalise. Each source value becomes an empirical percentile against a frozen reference distribution, then a pseudo-z through the inverse normal CDF, then S = 50 + 12.5·z, clamped to 0–100.
  2. Smooth. EPA NowCast over the trailing 12 observations, weight floor 0.5.
  3. Pillar. The mean of its live sources' smoothed scores. A pillar with no live source is dark; a pillar whose sources have no baseline yet is awaiting one. These are different states and are never merged.
  4. Composite. 0.7·mean(pillars) + 0.3·max(pillars), over live pillars only.
  5. Level. BLISS 5–1 from the composite, through the six-layer anti-flap state machine: Schmitt deadband of 3 points, dual-window dwell, a minimum interval between changes, a post-change lock, one step per change, and a 2-of-5 pillar quorum. A level change is frozen while any pillar is dark.

Every function in that list is imported from collector/engine.mjs — the same code that computes DOOMCON, not a second implementation of it. Two implementations that could disagree would destroy the only claim that makes the pairing worth anything, which is that the two numbers are commensurable.
