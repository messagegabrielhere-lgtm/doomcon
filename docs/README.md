# Docs index — start here if you are new

This repository powers **SIREN** .
The GitHub repo and site URL still say `doomcon` — that is the old name. The
product name is SIREN.

If you only remember one picture of the system, remember this:

```text
public data  →  collector/  →  data/  →  site/  →  GitHub Pages
   (APIs)        (count)      (JSON)    (HTML)     (the website)
```

Everything else (Arena, Scanner, Monitor, clipper, …) is a **side project**
that shares the brand and hosting, not the index formula.

---

## The core index (the main product)

| Piece | What it is, in plain words |
|---|---|
| [`collector/`](../collector/) | Programs that **fetch** public numbers and **score** them into one 0–100 reading and a DOOMCON level (5 = quiet … 1 = loud). |
| [`data/`](../data/) | The saved readings, history, and hash-chained **receipts** so anyone can re-check a number. |
| [`site/`](../site/) | Builds the static website from `data/` (no React app — plain HTML/CSS/JS generated by Node). |
| [`docs/METHODOLOGY.md`](METHODOLOGY.md) | The formula, constants, and “how this could mislead you”. |
| [`docs/CONTRACT.md`](CONTRACT.md) | The build rules agents and humans must not break (shapes, pillars, no secrets in git). |

**Typical local run** (Docker, no Node install needed):

```bash
docker run --rm --network host -v "$PWD":/app -w /app node:20-alpine \
  node collector/collect.mjs
docker run --rm -v "$PWD":/app -w /app node:20-alpine \
  node collector/engine.mjs
docker run --rm -v "$PWD":/app -w /app node:20-alpine \
  node site/build.mjs
```

Or on a machine with Node 20+: `npm run pipeline`.

## npm: when it is allowed

- **Never** for `collector/` and `site/` core scripts — Node built-ins only.
- **Allowed** for Arena and clipper (`@anthropic-ai/sdk`), and as a one-off CI
  install for PDF parsing in `investors/`.
- Root `package.json` exists so Arena’s CI can `npm ci`. It does not mean the
  index depends on npm.

## Naming cheat sheet

| You might see | It means |
|---|---|
| SIREN | The product / index name |
| DOOMCON | Old name; still in the URL, levels (SIREN 5→1), and repo |
| Receipt | A signed snapshot of every input that produced one reading |
| Pillar | One of five buckets that make up the composite score |
| Dark source | A data feed that failed this run (shown as missing, not guessed) |
