(posted 2026-10-05). X cut the post's own links at 32 characters, so most of them go to GitHub 404s.

moved, the current home is listed and the move is noted. Items 48 to 50 in the post repeat
items 7, 18 and 19, so the list has 47 distinct repos.

The numbering follows the post. The groups are added here.
