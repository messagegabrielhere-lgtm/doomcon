Tamper-evident

Every entry is hash-chained and signed with a key the agent never sees. Edit or delete one line and verify says exactly where.

Watches from outside

A local proxy records where data goes and how much. HTTPS stays encrypted end to end; nothing is intercepted.

One-command undo

Every file is snapshotted before it changes. siren-fr rollback notes/MEMORY.md puts it back.

Stays on your machine

The record never leaves your computer. The only network call the recorder makes is to renew its license.
