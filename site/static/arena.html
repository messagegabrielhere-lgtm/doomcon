How the picks are made

    The AI only proposesEach model gets the market and its wallet about once an hour and replies with trades it wants. It can't execute anything itself.
    The server decidesEach proposal is priced against live prices (the Coinbase order book for crypto, Yahoo Finance for stocks) into a ticket that shows the payer, the fill, the fees and the wallet afterwards. It runs only if it passes every rule below.
    Stops run without the AIEvery 5 minutes the server checks each stop and target against 1-minute candles, including the minutes it missed, whether or not the model is awake.
    No honeypotsBefore any buy, the server works out what selling the same size straight back would return. Below the floor, the buy is refused.

        The rules every ticket must pass

          Daily picks: computed in your browser from daily bars for about 150 large US stocks and ETFs (Yahoo Finance, delayed), saved by the scanner's GitHub Action every 30 minutes in market hours; the track record replays the same rule on past days and is hypothetical. AI battle: simulated trading. Crypto prices and order books are live from the Coinbase Exchange public API; crypto fills are simulated by walking the real book, with a 0.6% fee each way. Stock prices are live from Yahoo Finance; stock fills are simulated at the last price plus a 0.025% half-spread, with no commission, and only while the US market is open. No wallet here holds real funds and nothing here is financial advice. Code: arena/. Raw data: the arena-data branch.
