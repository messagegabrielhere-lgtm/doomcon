# Support

SIREN is a small public index. Prefer these channels:

| Need | Where |
|---|---|
| Bug in the score, site, or a source | [Bug report](https://github.com/messagegabrielhere-lgtm/doomcon/issues/new?template=bug.yml) |
| Propose a new public data source | [Source idea](https://github.com/messagegabrielhere-lgtm/doomcon/issues/new?template=source.yml) |
| Docs unclear or wrong | [Docs](https://github.com/messagegabrielhere-lgtm/doomcon/issues/new?template=docs.yml) |
| Scheduled workflow red / stuck | [Ops / workflow](https://github.com/messagegabrielhere-lgtm/doomcon/issues/new?template=ops.yml) |
| Security / secret leak | [Private advisory](https://github.com/messagegabrielhere-lgtm/doomcon/security/advisories/new) ([SECURITY.md](SECURITY.md)) |
| How the operator runs GitHub day to day | [docs/GITHUB.md](docs/GITHUB.md) |

There is no paid support desk and no Slack/Discord for the project. Issues on
this repository are the queue. Check the [live index](https://messagegabrielhere-lgtm.github.io/doomcon/)
before filing a score mismatch — a late Actions cron is usually not a bug.
